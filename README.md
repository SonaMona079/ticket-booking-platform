# Ticket Booking Platform

A web-based ticket booking platform for movies and concerts with an interactive seat selection feature.

## Features

- 🎬 Movie seat booking with visual seat selection
- 🎵 Concert ticket booking
- 🎨 Modern and responsive UI
- 💺 Interactive seat map

## Demo

Visit the live demo: [Ticket Booking Platform]([https://gaur-avvv.github.io/ticket-booking-platform](https://gaur-avvv.github.io/ModernUI-Ticket-Booking-Platform/))

## Getting Started

Simply open `index.html` in your web browser to start using the application.
